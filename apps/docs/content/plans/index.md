*Updated 2026-11-27.* 本目录集中跟踪 CVSA 各子系统的工程进度与中长期规划，使开源贡献者与 Coding Agent 能够基于同一份真实代码现状开展协作。每份路线图均明确区分 **当前状态**（可直接在仓库代码与运行配置中验证的事实）与 **演进方向**（待实施的后续里程碑）。

尚未进入实施排期的早期构想记录在 [想法与备忘](/zh/ideas)，已落地的跨模块约束与技术取舍记录在 [架构决策](/zh/decisions)。
